# Contact Analyzer contributor rules

- Preserve every SQLite database, browser profile, and user vault.
- Operate through a visible, authenticated Chrome or Chromium browser at
  `127.0.0.1:9222`.
- Passive inspection of XHR/fetch responses generated by that browser is
  allowed. Do not add official social-network API clients, API tokens, or
  API-key requirements.
- Canonical relationships are only `followers`, `following`, and `friends`.
- Persist contacts as canonical profile URLs. Never save post, media, search,
  hashtag, group, repository, or navigation URLs as contacts.
- Put platform-specific adapter changes in
  `contactanalyzer_app/adapters.py` and targeted collection changes in
  `contactanalyzer_app/collector.py`.
- Never loosen a profile URL normalizer just to increase a count. False
  profile URLs are worse than an incomplete run.
- Keep incomplete runs explicitly marked incomplete.
- Never commit browser profiles, authentication artifacts, case bundles,
  databases, screenshots, rendered HTML, or collected subject data.
- Run `python -m unittest discover -s tests -v` before finishing a change.
